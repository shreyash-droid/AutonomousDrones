    Aircraft hardware & wiring

    Every block below has driver code in this project. In simulation the three blue blocks are replaced by software models with the same interface.

    Onboard pipeline (every photo)

    1. Capture nadir photo at survey point (10 m AGL, ≈1 cm per pixel)
    2. Detect crop / weed with YOLO11 on the Pi (NCNN, ~250 ms)
    3. Georeference pixel → metres → GPS using altitude, FOV & heading
    4. Safety filter drop weeds within 15 cm of a crop plant
    5. Cluster nearby weeds → one spray shot per cluster
    6. Spray descend to 3 m, hover, pulse the pump 600 ms
    7. Map log every weed to CSV / GeoJSON / KML for the farmer

    Failsafes

    • Battery < 25 % → companion RTL (Pixhawk BATT_FS also armed)
    • Geofence breach / altitude > 30 m → RTL
    • Telemetry or companion link loss → Pixhawk FS_GCS → RTL
    • Sprayer heartbeat lost 3 s → MCU disarms pump
    • RC kill switch (CH8) cuts the pump in hardware
    • Tank empty (float switch) → continue in survey-only mode
